# apks/

ضع هنا ملفات `.apk` التي تريد أن تظهر في قائمة «تطبيقات جاهزة» داخل الموقع.

- القائمة تتغير تلقائياً حسب الملفات الموجودة هنا: أضف ملفاً فتظهر، واحذفه فيختفي.
- بعد إضافة ملف أو حذفه شغّل `npm run build` ثم اعمل commit لـ `manifest.json` وللملف.
- الأسماء المسموحة: حروف لاتينية وأرقام و`.` و`_` و`-` فقط، وتنتهي بـ `.apk`.
- لا تضع هنا إلا ملفات تثق بمصدرها. الأداة تتحقق من بصمة SHA-256 قبل التثبيت، لكنها لا تفحص محتوى التطبيق.
